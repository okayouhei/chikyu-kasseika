# 地球活性化実行委員会 LINE連携Bot「活性化くん」

LINEグループに招待して使うBotです。

| 機能 | 使い方 |
|---|---|
| イベント告知の自動投稿 | `予定追加` で登録 → **3日前にAIが告知文を作って自動投稿**。`告知 3` で手動投稿も可 |
| リマインド | 登録した予定を **前日・1時間前** に自動投稿 |
| 日程調整 | `日程調整 打合せ / 11/5 19:00 / 11/6 20:00` → ボタンで投票 → `日程確定 1 1` で予定に自動登録 |
| 要約・議事録 | `要約` / `要約 3日` / `議事録開始` → `議事録終了` |
| 質疑応答 | `@活性化くん 質問` または `質問 ○○`（グループの会話と予定を踏まえて回答） |
| ヘルプ | `ヘルプ` |

区切りの `/` は **前後にスペース** が必要です（`11/5` の日付と区別するため）。
日時は `11/1 14:40`、`2026/11/1 14:40`、`11月1日 14時40分`、`明日 10:00`、`来週水曜 19:00` が使えます（日本時間）。

## セットアップ

### 1. LINE側（LINE Developers）
1. 開発者アカウントのメールアドレスを認証する
2. プロバイダー → **Messaging APIチャネル** を作成
3. **チャネルシークレット**（チャネル基本設定）と **チャネルアクセストークン(長期)**（Messaging API設定）を控える
4. Messaging API設定で **「グループトークへの参加を許可」オン／「応答メッセージ」オフ**
5. デプロイ後、**Webhook URL** に `https://<公開URL>/webhook` を設定し「Webhookの利用」をオン → 「検証」
6. チャネルのQRコードからBotを友だち追加し、グループに招待する

### 2. サーバー
Webhookを受け、毎分リマインドを確認するため **常時起動できる環境**（Render / Fly.io / Railway / VPS 等）が必要です。
Cloud Run等のスケールゼロ環境ではリマインドが動きません。SQLiteファイルは永続ボリュームに置いてください。

```bash
cp .env.example .env   # 値を設定
node --env-file=.env src/server.js
# または Docker: docker build -t kasseika-bot . && docker run -p 3000:3000 -v kasseika:/data --env-file .env kasseika-bot
```

Node.js 22.13+ が必要で、外部パッケージは使っていません。テストは `npm test`。

`ANTHROPIC_API_KEY` が未設定でも予定・日程調整・リマインドは動き、AI機能（告知文・要約・議事録・質問）だけ無効になります。

## プライバシー
- 要約・議事録・質問の文脈用に、グループの**テキスト発言**をSQLiteに保存します（既定30日で自動削除、`RETENTION_DAYS`で変更）。
- 参加メンバーには導入時に周知してください。Botは参加時にもその旨を投稿します。`記録停止` で保存を止められます。
- AI機能を使うと、該当部分の発言がClaude APIに送信されます。
- 画像・スタンプは保存・解析しません（ポスター画像の読み取り等は今後の拡張候補）。
- 秘密情報（シークレット・トークン・APIキー）は環境変数のみに置き、リポジトリにコミットしないでください。
