夢フェスとは

「ゆめのたね」が主催する公開収録イベントです。当日は、地球活性化実行委員会がゲストとして出演します。

地球活性化実行委員会とは

電動車椅子で暮らす岡ちゃんの呼びかけで始まった、広島の市民グループです。障がいのある方も、ない方も、どなたでも気軽に集まり、知り合い、助け合える場所づくりを進めています。

会場に来られない方も、参加できます

  • 参加したい方:交流イベントなどの情報を受け取れます。
  • 撮影・SNS担当:写真や動画で活動を伝える仲間です。スマホ1台で大丈夫です。
  • 応援メンバー:LINEで情報を受け取るだけでも、立派な応援です。
